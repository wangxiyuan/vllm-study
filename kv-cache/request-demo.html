⑥ 为什么 group 是“跨层”的？
例外：DeepSeek V4.1 的 compressed KV 是模型级共享（source 层 2/8/14/20 写，consumer 层读），这是“真的跨层复用内容”；普通 GQA/MLA 不是。Kimi/Qwen/GLM 的 KDA/GDN state 也是每层自己的，不共享。
⑦ 这里没有 CircularBufferSpec，因为它不是按 token 增长的 paged KV
token 级 cache 只覆盖 GQA / MLA；compressor state、indexer tail、QSA ring 用的是 CircularBufferSpec：每请求 1 个 block，按 pos % ring 原地覆盖，uses_slot_mapping=False，不参与前缀缓存。它们的覆盖行为见互动实验室的 **Ring / CircularBuffer** 页签。
